# 台電職員電機歷屆試題詳解刷題網站

## 使用方式
1. 解壓縮後直接雙擊 `index.html`。
2. 可依年度、主題、錯題/收藏篩選。
3. 108–112 年科目 A 依題本中官方答案標記自動判分。
4. 113–114 年目前上傳的是試題本，網站保留題目但不虛構答案。
5. 科目 B 為申論題，已收錄原始 PDF 供閱讀。

## 功能
- 350 題科目 A 題庫（108–114，每年 50 題）
- 108–112 年共 250 題可自動判分
- 題目主題分類、搜尋、隨機出題
- 錯題與收藏
- localStorage 保存進度
- 一鍵跳到原始 PDF 題本頁

## 注意
部分題目含電路圖，純文字抽取無法完整呈現圖形；請按「查看原始題本」搭配閱讀。
